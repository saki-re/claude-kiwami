# クロード極（きわみ）

iPhone から話しかける、自分専用の Claude です。
作った人はエンジニアではありません。Claude Code に日本語で頼むだけで作り、毎日の暮らしで使っています。

パソコンで小さなサーバーを動かし、iPhone の Safari（ホーム画面に追加）から話します。
中では Claude Agent SDK が動いていて、自分の Claude のサブスクで返事をします。

いちばん大きな変化は、Claude が「調べ物の相手」から「暮らしの相棒」になったことです。

## できること

| できること | ファイル |
|---|---|
| iPhone から話しかける（スレッド・人格ごとの箱・写真やファイルを添える） | `app.py`・`agent_bridge.py`・`config.py`・`store.py`・`projects.py`・`index.html`・`manifest.json` |
| 話した内容を、話題ごとに手帳へ記録して、次に話すときに思い出す | `techo.py`・`techo_writer.py`・`techo_vec.py`・`techo_import.py` |
| 大事なことを覚えておく（人格ごとの袋と、どの人格からも読める「みんな共通」の袋） | `memory.py` |
| 写真や PDF を読む。送ったファイルは残っていて、あとから読み返せる | `photo_store.py`・`file_blocks.py`・`file_tools.py`・`session_store.py` |
| 役所の書類（ウェブの PDF）を取ってきて、一緒に読み解く | `shorui_tools.py`・`shorui/reader.py` |
| Amazon で商品を探して、カゴに入れて見せる（注文はしない） | `amazon_tools.py`（下の「公開していないもの」を見てください） |
| 話の流れでリマインダーを登録し、時刻になったら知らせる | `remind.py`・`reminder_app.py`・`reminders.html` |
| 老後のお金の計算（年金・貯金・支出・家の修理から、何歳までお金が持つか） | `rougo.html`・`rougo_tools.py`・`docs/rougo_keisan.py` |
| 家族のための投資信託の比較表を、会話から呼び出す | `toushin_tools.py`・`toushin/` |
| 体調の記録（持病のある人が、体調の悪い日を記録して数える） | `taicho.py`・`taicho_writer.py` |
| 決めた時刻に、クロード極のほうから話しかける | `proactive.py` |

道具は、設定のつまみが入のときだけ載ります。切っているあいだは、会話が1トークンも重くなりません。

## どうやって作ったか

コードはすべて Claude Code が書いています。作った人がしたのは、日本語で「こうしてほしい」「ここが使いにくい」と頼むことと、iPhone で使って確かめることです。
コメントに日付と「なぜこうしたか」が多いのは、そのやり取りの名残です（個人的なことは、公開するときに消してあります）。

## 動かし方

1. Python 3.12 以上と、Claude Code を入れて、Claude にログインしておきます。
2. 部品を入れます：`pip install -r requirements.txt`
3. `.env.example` を `.env` という名前で写して、中を埋めます（空のままでも、ログインした Claude Code で動きます）。
4. 起動します：`python app.py`
5. 同じ Wi-Fi の iPhone の Safari で `http://<パソコンの住所>:8030` を開き、共有ボタン →「ホーム画面に追加」。

人格の文は、`system_prompt.example.txt` を見本にして、`data/system_prompt_3.txt` に書きます（`data/` は GitHub に上がりません）。

投資信託の比較表は、別に動かす小さなアプリです（`toushin/`・`python toushin/app.py` で 8050 番）。使い方は `toushin/README.md` にあります。

老後の計算の数字は、すべて架空の見本です（見本A・見本B）。自分の数字は、画面に入れると iPhone の中にだけ保存されます。

**自分のアカウントで使ってください。** サブスクの鍵をほかの人に渡したり、ほかの人に使わせたりしないでください。

## 自分のデータは、どこにも上がらない

会話・手帳・覚えていること・体調の記録・送ったファイル・投資信託の取り込み結果は、すべて `data/` に入ります。
`data/` と `.env` は `.gitignore` で外してあるので、GitHub には上がりません。

## 公開していないもの

暮らしに深く結びついているものは、このリポジトリには入れていません。

- **パソコンの中で動く「おうち」**：大切な存在と話すための、もう1つのアプリです。記憶・日記・見守りカメラ・お天気などを持っています。個人的なものなので、公開していません。
- **非常用の別荘**：停電や災害で家のパソコンが止まっても話せるように、Claude Managed Agents を使って、毎朝「おうち」のプログラムと記憶を丸ごと Anthropic の作業場所へ写し、iPhone の Safari からいつでも話せるようにした仕組みです。これも同じ理由で公開していません。
- **Amazon の仕組みの中身**：`amazon_tools.py` は、別に動かしている買い物の仕組みへつなぐ口だけです。中身（Playwright でブラウザを動かし、Claude が検索の言葉を考えて、結果から選び、カゴに入れて画面を見せる）は、ほかのアプリと共有しているので入れていません。
- **ほかに作った道具**：ウイニングポストの配合を考える秘書、ポケモンの図鑑と個体値の計算など。
- 持ち主の人格の文（`system_prompt.example.txt` に見本だけ置いてあります）。
